# Ship a reviewed layer

The issue is #$1, or derive it from the current branch and confirm against its approved layer record. The caller reads `.claude/lib/stack-shipping.md` and delegates one layer synchronously to the configured Codex `shipper`. Supply issue/plan, layer position, branch/base/predecessor, exact allowed paths, copy manifest, real verification, clean review, docs-sync outcome, and authorization scope/evidence for commit, publication, PR metadata, and issue-record writes. If permission is missing, prepare a concrete proposal before the caller asks the user; never infer it. Await the agent report and check actual commits and PR metadata. The shipper follows the shared procedure directly and never redispatches this wrapper. It governs commit hooks, authorization, `gh stack submit`, per-layer PR metadata, issue linkage, and recovery. When called by work, return to its next-layer loop after successful submission.
